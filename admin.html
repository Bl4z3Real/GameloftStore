Gameloft Store — Pannello Admin

Aggiungi giochi e trailer senza scrivere codice a mano.

Come funziona
  1. Compila il modulo qui sotto per ogni gioco e premi "Aggiungi gioco alla lista" — oppure carica un games-data.js esistente per modificarlo.
  2. Ripeti per tutti i giochi che vuoi aggiungere o rimuovi quelli che non ti servono.
  3. Premi "Scarica games-data.js" per ottenere il file già pronto, oppure copia il codice generato.
  4. Carica il file ottenuto nella tua repository, sostituendo quello vecchio.
  5. Salva/pubblica: i giochi compariranno automaticamente sia nella versione mobile che in quella desktop.
